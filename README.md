# DevJournal — Multi-Page Blog Website

A modern, responsive, three-page blog website focused on web development, coding tips, and beginner-friendly learning resources.

**Project:** The Sky Gen — Project 03  
**Reference:** TSG/WD/P03/2026  
**Category:** Web Development  
**Level:** Beginner  
**Built With:** HTML5 and CSS3

## About the Project

DevJournal is a multi-page blog website designed to help beginner developers explore web development topics through a clean, modern editorial-style interface.

The project demonstrates multi-page navigation, reusable styling, responsive layouts, semantic HTML, and organised file management.

## Pages

### 1. Home — `index.html`
- Hero section introducing DevJournal.
- Introduction to the website.
- Featured blog articles.
- Calls to action linking to other pages.
- Shared navigation and footer.

### 2. Blog — `blog.html`
- Four blog post cards.
- An image, title, publication date, and preview for each post.
- Topics covering HTML, CSS, JavaScript, responsive design, and clean code.
- Links to individual article sections.

### 3. Contact — `contact.html`
- Contact information.
- Styled contact form with name, email, subject, and message fields.
- Required-field validation through HTML.
- Shared navigation and footer.

**Note:** The contact form is a front-end demonstration and is not connected to an email service or backend.

## Features

- Three interconnected HTML pages.
- One shared CSS stylesheet.
- Consistent header, footer, typography, and colour palette.
- Active page indicators in navigation.
- Responsive layouts for desktop, tablet, and mobile.
- CSS Grid and Flexbox layouts.
- Semantic HTML5 elements.
- Accessible form labels and image alternative text.
- Google Fonts typography.
- Hover effects and interactive navigation links.
- Organised project folders.

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Navigate between Home, Blog, and Contact.
5. Resize the browser to test the responsive layouts.
